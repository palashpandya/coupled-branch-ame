# Coupled-branch families of AME states

Created: 21 October 2026 · Last updated: 21 October 2026

Companion repository for [Coupled-branch families of AME states](https://palashpandya.github.io/research/ame/coupled-branch-families/).

**Manuscript in preparation. Repository visibility: private (confirmed 21 October 2026).**

## Current contents

This initial package records the announced parameter families, the eight finite
examples, and the exact source of that information. The manuscript,
construction definitions, matrices, and verification programs have **not yet
been imported**. This package does not currently reproduce or independently
certify the states.

## Announced families and examples

In the table below, `p` is prime and each physical party has local dimension
`d = 2p`.

| Parties N | Infinite family | Explicit local dimensions d | Binary branches |
| --- | --- | --- | --- |
| 13 | AME(13, 2p), p >= 17 | 34, 38, 46 | 16 |
| 15 | AME(15, 2p), p >= 17 | 26, 34, 38, 46 | 8 |
| 17 | AME(17, 2p), p >= 67 | 134 | 64 |

AME(15,26), with p = 13, is an additional finite example below the sufficient
threshold of the stated 15-party infinite family. The thresholds are
sufficient conditions for these constructions; they are not nonexistence
bounds below them.

The [machine-readable catalogue](data/catalogue.json) distinguishes the
announcement's verification claims from verification performed by this
repository.

## Construction overview

The announcement describes a coherent coupling of binary and prime-dimensional
branches. The binary branches have maximally mixed small-party marginals on
average, while the prime-dimensional branches carry the branch labels without
revealing them to the relevant subsets. The infinite families are attributed
to a Cauchy-matrix construction. The explicit branch data and full hypotheses
must be taken from the manuscript and its construction files.

## Scope of the contribution

To our knowledge, these particular AME families have not previously been
reported. The coupled-branch principle is established, and the classical code
ingredients have precedents. The contribution is the explicit realization of
the stated families and finite examples, together with exact certificates.

This wording follows the announcement; this repository has not performed a
separate literature review.

## Reproducibility status

No construction code has been run as part of this initial repository package.
The announcement reports exact arithmetic checks for the finite examples and
a Cauchy-matrix argument for the infinite families. These are attributed source
claims, not results generated by the files currently present here.

Once the original construction materials are imported, the documentation
should specify the basis and branch conventions, exact arithmetic domains,
generation commands, verification commands, and the resulting certificates.
